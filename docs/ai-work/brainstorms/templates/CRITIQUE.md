# Cross-review

| Field | Value |
|---|---|
| Brainstorm / contribution / slot | stable ids |
| Actor | model, tool, effort, session, canonical capability and raw input |
| Submitted | UTC timestamp |
| Confidence | high, medium, or low |

## Evidence examined

- Name the question, all positions, and any evidence independently checked.

## Agreements

Identify claims that survive comparison and why.

## Challenges

Find unsupported transfers, hidden assumptions, missing alternatives, risks, or errors.

## Better option or combination

Offer an outside-the-box alternative when it improves the outcome.

## Remaining disagreements and evidence gaps

Preserve unresolved issues; do not manufacture consensus.

## Falsification tests

Name the cheapest decisive check for the contested claims.
