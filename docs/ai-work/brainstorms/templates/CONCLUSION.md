# Brainstorm conclusion

| Field | Value |
|---|---|
| Brainstorm / contribution / synthesis slot | stable ids |
| Synthesizer | model, tool, effort, session, canonical capability and raw input |
| Submitted | UTC timestamp |
| Confidence | high, medium, or low |

## Decision

State the selected direction in a few lines.

## Why

Apply the original decision criteria to the evidence, positions, and critiques.

## Rejected alternatives

Keep the strongest alternatives and the reason each lost.

## Remaining dissent

Record material objections even when the brainstorm concludes.

## Assumptions, gaps, and transfer risks

Say what is not known and what context could change the decision.

## Falsification and review triggers

Define evidence that should reopen or supersede this conclusion.

## Task-ready next steps

Describe possible work units without publishing or authorizing them. The owner must
separately say `CREATE TASKS FROM BRAINSTORM <id>`.
