# Task status

| Field | Value |
|---|---|
| Task | `<task-id>` |
| State | `proposed` |
| Sequence | `0` |
| Active attempt | none |
| Active worker | none |
| Last event | `<event-id>` |
| Updated at | `<UTC RFC3339>` |
| Next capability | `<HIGH or LOW>` |
| Next work role | `<role>` |
| Branch | `<canonical branch>` |
| Worktree | `<canonical worktree>` |

Current blockers, resumable state, and exact next action go here. The immutable event
files are authoritative for history.
