# Proposed scientific backlog

These items improve later editions but do not block an honest v1. They are HIGH planning
tasks only. Claiming one authorizes a protocol and handoff, not implementation or
measurement. Its protocol must create separately reviewable LOW/either execution tasks.

1. Complete Study 04's eight missing designs, repeated randomized trials, cardinality,
   cadence/churn, YugabyteDB, equal-total resources, and verified placement.
2. Complete Study 05's real-TTL churn, medium scale, repeats, full cache resource budget,
   YugabyteDB/cluster/placement, and open-loop demand.
3. Design a real topology study with balanced endpoints, independent hosts, injected
   latency, node/endpoint loss, and per-node/equal-total budgets.
4. Design the first native cross-major datastore comparison in the configuration domain.
5. Design analytical/search/read-model comparisons for dashboards and top-N workloads.
6. Design a hierarchy study comparing adjacency list, materialized path, closure table,
   nested sets, and bounded embedding.

Every protocol must satisfy current methodology, name all coverage gaps, include
correctness controls, and remain unmeasured until separately authorized and claimed.
