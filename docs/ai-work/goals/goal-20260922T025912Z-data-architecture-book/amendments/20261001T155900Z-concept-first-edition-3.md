# Goal amendment — concept-first Edition 3

**Amendment id:** `20261001T155900Z-concept-first-edition-3`

**Recorded at:** `2026-10-01T15:59:00Z`

**Owner request (2026-10-01):** change the book's method — present the concepts, and use the
case studies to show when they fit. Improve the didactics. Avoid long texts, because they make
the book harder to understand.

**Owner choices (same session):** pilot one chapter first and approve the style before the rest
is converted; case studies appear as short boxes inside each concept plus a one-page profile per
study; evidence shows inline as a compact one-line badge, with full claim cards only in the
evidence index.

## Decision

The reader-facing layout changes from family-first to **concept-first**. The rules are in
[`book/STYLE.md`](../../../../../book/STYLE.md), which is now their single source.

This replaces the REQUEST.md rule that "every family, variant, topology and scenario follows one
progressive structure". Each element of that structure keeps a home:

| Progressive structure item | Edition 3 home |
|---|---|
| 1 Plain-language quick choice | concept opener (key idea) |
| 2 Where it thrives and perishes | fit table |
| 3 Common scenarios | case boxes |
| 4 Reusable mechanism | "How it works" |
| 5 Read/write/storage/correctness/operational costs | cost table |
| 6 Direct evidence | claim badges, full cards in the evidence index |
| 7 Unmeasured boundaries | "Not measured yet" gap callouts |
| 8 Reproduction links | study profiles |

## Effect

- The six-family taxonomy, the variants and topology stay covered; they are organised by concept.
- Unchanged: the evidence registry, claim ids, gap kinds, methodology 15 (figures) and 21 (the
  eight-question checklist, now a compact table), the provenance page and the build gates.
- No measurement is authorised. No number is added: every number on a page comes from a cited
  claim.
