# Archived history

Living documents in this repository are rewritten as the project moves on. When a rewrite
would destroy provenance, the previous edition is copied here under a clock-generated UTC
name instead of being deleted, and the live document links back to it.

| Archive | What it is | Replaced by |
|---|---|---|
| [`context/`](context/) | Complete pre-rewrite editions of the root `CONTEXT.md` status narrative | [`CONTEXT.md`](../../CONTEXT.md) (one concise current status per study/task) |

Nothing here is edited after it is written. If a fact in an archived document is later
superseded, the new conclusion is recorded in the live documents (or in a signed report
under the relevant study), not by rewriting the archive.
